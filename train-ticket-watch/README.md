# train-ticket-watch：12306 余票监控 skill（Claude Code 用）

说一句「帮我盯 10 月 1 号杭州到南京早上的票，两个人」，Claude 就会每 10 秒查一次 12306 余票，
一有车次从「没票」变成「有票」，立刻告诉你「几点发车 · 车次 · 座位 · 剩几张」，你自己去 12306 / 飞猪 / 携程 App 抢。
它不会替你下单。

## 安装

1. 需要：Claude Code、Node.js 18+（`node -v` 看版本）。第一次运行会自动用 npx 下载 `12306-mcp`。
2. 把这个文件夹放到 `~/.claude/skills/` 下，最终路径是：
   `~/.claude/skills/train-ticket-watch/SKILL.md`
   ```bash
   mkdir -p ~/.claude/skills && unzip train-ticket-watch.zip -d ~/.claude/skills/
   ```
3. 重开一个 Claude Code 会话，skill 就会自动出现。

## 用法

- 「帮我盯 10 月 3 号南京回杭州下午的票，两个人」
- 「10.1 杭州到南京早上 5 点到下午 2 点，有二等座或一等座就叫我，10 秒查一次」
- 「先看一下现在还有什么票」（只查一次，不持续盯）
- 「停」「出票成功了」→ 停止监控

## 小贴士

- 退票座位通常只停留几十秒，手机 App 提前停在下单页、勾好乘车人。
- 同时在 12306 给目标车次挂「候补」，系统自动兑现比手抢快；出票后记得取消剩下的候补。
- 凌晨 0–6 点发车的车，在 12306 上日期要选当天。
