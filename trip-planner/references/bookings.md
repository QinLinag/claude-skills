# 逐个过预约 + 审核订单截图

## 节奏：一个一个来
用户在手机上办，一次只能盯一件事。每次只讲一项，格式固定，方便他照着点：

```
## ② 夫子庙核心区预约
- 在哪约：微信/支付宝小程序「南京夫子庙」，免费
- 日期：10 月 1 日（周四）
- 人数：两个人一起约（实名，姓名 + 身份证号）
- 时段：选能覆盖 19:00–19:30 入场的那一档（按计划 19:25 从西牌坊进）
- 为什么要约：……
- 万一满了：……（具体到改哪个时段、行程怎么挪）
办好告诉我，接着 ③ 六朝博物馆。
```

顺序：用户手上正开着的先办 → 一定要约否则进不去的 → 建议提前买的 → 餐厅订座 → 可选项。最后给一张总表：项目 / 日期时间 / 在哪办 / 状态。

## 时间敏感的事
- 热门景点常见规则：**提前 7 天、每天固定时间（如 16:00）放票**；临近出发全满时只剩「回流票」：放票时间点附近、入园当天早上（官方会投放退改名额）。给用户定闹钟提醒，提前 1 分钟进小程序等。
- 有的会出「付费选项」（如 5 元明信片联票），名额独立，免费的抢不到可以试。
- 评论区说「私我」「能代约」的基本是黄牛，提醒别信。
- 餐厅：热门店节假日晚市常常提前一两天约满。先查目标店两天的晚饭和午饭；都满就换同片区口碑接近的店，或者把正餐挪到饭点之外。

## 审核订单截图：逐张核对这些
- **日期**对不对（尤其跨月、「明天/后天」）。
- **时段**：博物馆分时段的票，看开始和**结束**时间（截断时让用户点「更多」）；结束得早就调整前面的行程（例如寄存完行李改打车）。
- **人数/张数**，以及**是否两人共用一个码**（共用就得一起进）。
- **餐厅订座**：看清是**午餐还是晚餐**、具体几点（实战中把 17:50 的晚饭订成了 11:00 午餐）；「待商家确认」要等短信，告诉用户大约几点会来。
- **退改规则**：随时退 / 过期自动退 / 不可退；有没有使用年龄范围（成人票 19–59 岁之类）。
- 截图里有完整身份证号、手机号：**不要在回复里复述**，并提醒用户别把这些截图发到群里或朋友圈。

## 行程后
没去的地方提醒退款：标「随时退」的去订单里申请；「过期退」的看是否已自动退；联票用过一部分通常不能部分退。
