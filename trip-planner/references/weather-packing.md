# 天气 → 穿什么、带什么

## 什么时候查
- **定行程时**（出发前 3–7 天）：看大趋势，有没有连续雨、台风、寒潮。主线里户外点多的那天如果有大雨，提前和室内备选对调。
- **出发前一天**（必查）：定最终的穿衣和装备，回复给用户一句话结论，并更新 plan.json 的 `packing` 和每天的 `weather`，重新生成交付物。
- **当天早上**（用户问的时候）：看下雨的时段落在哪一段行程，必要时把室内点挪到雨里。

```bash
python3 ~/.claude/skills/trip-planner/scripts/weather.py <城市> <开始> <结束> [--spots 景区1,景区2] [--up 山比市区高的米数]
```
脚本给中国天气网（城市 + 景区单独预报）和 Open-Meteo（体感、降雨时段、阵风、紫外线、湿度）两路数据，并按下面的规则给建议。两个来源不一致时取更保守的（更冷、更可能下雨）。

## 穿衣：按「出门活动时段」的体感温度分层
不要按凌晨最低温定（人在睡觉），用 7–22 点里最冷的体感温度；早晚和中午分开给建议。

| 体感温度 | 穿什么 |
|---|---|
| ≥28℃ | 短袖 + 防晒（帽子/防晒衣） |
| 23–28℃ | 短袖或薄长袖 |
| 18–23℃ | 长袖 + 一件薄外套（风衣/薄夹克/卫衣） |
| 12–18℃ | 长袖 + 厚一点的外套 |
| 5–12℃ | 毛衣或抓绒 + 厚外套 |
| <5℃ | 羽绒服 + 保暖内衣 + 帽子手套 |

再按场景加减：
- **早晚温差 ≥8℃**：洋葱式穿法，外套要能塞进包里。
- **爬山**：海拔每高 100m 约降 0.6℃，山顶风大再加一层防风（如黄山光明顶比山下低 10℃ 以上，夏天也要带外套）。
- **湖边、江边、城墙上、坐船、夜游**：风大体感更冷，比同时段市区多穿一层。
- **夏天室内**：博物馆、高铁空调冷，带一件薄长袖。
- **南方冬天**：室内没暖气，湿冷，比同温度的北方难受，多带保暖内衣。

## 下雨：伞还是雨衣
| 情况 | 带什么 |
|---|---|
| 降雨概率 <30% 且雨量 <1mm | 一把折叠伞备用（晴雨伞，也能挡太阳） |
| 会下雨，城市里走走 | 每人一把折叠伞 |
| 风大（阵风 ≥6 级，伞容易翻）/ 爬山 / 坐船 / 骑车 / 排长队 / 雨量 ≥10mm | **加一次性雨衣**（便宜、轻、能塞包）；鞋子选防水防滑的，带一双备用袜子 |
| 大雨、暴雨、雷暴 | 雨衣 + 鞋套或防水鞋；手机、身份证装密封袋；户外点换室内备选；雷暴时远离山顶、湖边空旷处 |

雨会落在哪几个小时，脚本会列出来，对照行程说清楚「影响的是哪一段」，比如「10/2 15–18 点，正好是中华门、老门东和去车站那段」。

## 其他天气情况
- **紫外线 ≥6**：防晒霜、帽子、墨镜；**3–6**：涂点防晒。
- **又热又潮**（≥28℃ 且湿度 ≥75%）：速干衣、多带一件替换的 T 恤。
- **大风**：外套选防风的，帽子容易被吹跑。
- **季节性风险**：江南 6–7 月梅雨（天天带伞，鞋子选防水的）；7–9 月东南沿海台风（关注航班、高铁和景区临时关闭）；北方春天沙尘（口罩）；冬天寒潮（看最低温和降雪对交通的影响）。

## 跟活动走的装备
- **步行量大**（每天 ≥10km、台阶多，如中山陵 392 级、城墙）：好走防滑的鞋，别穿新鞋；创可贴。
- **古镇、石板路、雨后的城墙**：鞋底要防滑。
- **爬山**：登山鞋、手套（有铁链的路段）、护膝按需、水和能量零食。
- **海边、湖边**：防晒、拖鞋、防水手机袋。
- **带吃的回程**（如盐水鸭）：保冷袋或密封袋。

## 每次都带
身份证原件（高铁、景区实名、安检都要）、充电宝（≤100Wh，随身，不能托运；预约码、乘车码、车票全在手机上）、纸巾湿巾、水、常用药（创可贴、肠胃药，晕车的带晕车药）。

## 怎么跟用户说
先给结论，一两行讲清楚：
> 要带长袖，最好再带一件薄外套。10/2 下午到傍晚有小雨，正好是中华门、老门东那段，带两把折叠伞。

然后再列预报表和理由；预报跟上一次比有变化（比如雨从 10/1 挪到了 10/2）要明确说出来。
